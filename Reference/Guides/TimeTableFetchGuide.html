Authentication

POST /sso/api/account/oauth2/token

Mobile login endpoint. Bypasses ReCaptcha by setting Captcha: "-" and MobileAppPlatform: "android". Returns a JWT used for subsequent web portal calls.

Request Headers
HeaderValue
Content-Typeapplication/jsonREQUIRED
x-applicationnameoneportalREQUIRED
x-requestfrommobileREQUIRED
Request Body
FieldTypeNotes
UserIdstringYour UPES emailREQUIRED
PasswordstringYour passwordREQUIRED
CaptchastringUse "-" to bypassREQUIRED
MobileAppPlatformstring"android" or "ios"REQUIRED
cURL Example
curl 
curl --location 'https://myupes-beta.upes.ac.in/sso/api/account/oauth2/token' \
  --header 'Content-Type: application/json' \
  --header 'x-applicationname: oneportal' \
  --header 'x-requestfrom: mobile' \
  --data-raw '{
    "UserId": "Nikhil.12509@stu.upes.ac.in",
    "Password": "YOUR_PASSWORD",
    "Captcha": "-",
    "MobileAppPlatform": "android"
  }'
🔑
Extract the JWT from the response Token is at Item.Identity.AccessToken. Pass it as Authorization: Bearer <token> on all subsequent portal requests alongside x-appsecret.

Full Python Script

A minimal script that logs in, fetches the student ID, then retrieves today's timetable. Replace credentials with environment variables in production.

python 
import requests
from datetime import datetime

BASE = "https://myupes-beta.upes.ac.in"
APP_SECRET = "ku7GUMtyT8er51rTfTc7HC"

PORTAL_HEADERS = {
    "Content-Type": "application/json",
    "x-applicationname": "connectportal",
    "x-appsecret": APP_SECRET,
    "x-requestfrom": "web",
}

def login(email: str, password: str) -> str:
    """Logs in and returns the Bearer token (Item.Identity.AccessToken)."""
    resp = requests.post(
        f"{BASE}/sso/api/account/oauth2/token",
        headers={
            "Content-Type": "application/json",
            "x-applicationname": "oneportal",
            "x-requestfrom": "mobile",
        },
        json={
            "UserId": email,
            "Password": password,
            "Captcha": "-",
            "MobileAppPlatform": "android",
        },
    )
    resp.raise_for_status()
    return resp.json()["Item"]["Identity"]["AccessToken"]

def get_student_id(token: str) -> str:
    """Returns the StudentId GUID needed for timetable calls."""
    resp = requests.get(
        f"{BASE}/apigateway/connect-portal/api/studentloginbasicinfo",
        headers={**PORTAL_HEADERS, "Authorization": f"Bearer {token}"},
    )
    resp.raise_for_status()
    data = resp.json()
    return data["Items"][0]["StudentId"]

def get_timetable(student_id: str, date: datetime = None, token: str = "") -> list:
    """Fetches the timetable for a given date (defaults to today)."""
    if date is None:
        date = datetime.today()
    date_str = date.strftime("%d-%b-%Y")  # e.g. 17-Oct-2026

    resp = requests.post(
        f"{BASE}/apigateway/api/timetable",
        headers={**PORTAL_HEADERS, "x-studentUniqueId": student_id, "Authorization": f"Bearer {token}"},
        json={
            "ActivityCode": "studentdashboard",
            "TimeTableContextDetails": {
                "SlotStartDate": date_str,
                "SlotEndDate": date_str,
                "StudentCode": student_id,
            },
        },
    )
    resp.raise_for_status()
    return resp.json()

def print_timetable(slots: list):
    """Pretty-prints the timetable."""
    if not slots:
        print("No classes today.")
        return
    for slot in sorted(slots, key=lambda s: s["SlotStartTime"]):
        if slot.get("IsCancelledSlot"):
            continue
        subject = slot["ModuleList"][0]["ModuleName"] if slot["ModuleList"] else "—"
        teacher = slot["TeacherList"][0]["Name"] if slot["TeacherList"] else "—"
        venue   = slot["FloorPlanDetails"]["VenueName"]
        vtype   = slot["FloorPlanDetails"]["VenueCategory"]
        link    = slot["FloorPlanDetails"].get("MeetingLink", "")
        print(f"  {slot['SlotStartTime']} – {slot['SlotEndTime']}")
        print(f"    {subject}")
        print(f"    {teacher}  |  {venue} ({vtype})")
        if link:
            print(f"    Teams: {link}")
        print()

if __name__ == "__main__":
    import os
    EMAIL    = os.environ["UPES_EMAIL"]
    PASSWORD = os.environ["UPES_PASSWORD"]

    print("Logging in…")
    token = login(EMAIL, PASSWORD)

    print("Fetching student ID…")
    sid = get_student_id(token)
    print(f"  StudentId: {sid}")

    print("\nToday's timetable:")
    slots = get_timetable(sid, token=token)
    print_timetable(slots)
⚠️
Note on authentication Both x-appsecret AND Authorization: Bearer {token} are required on portal calls. The x-appsecret identifies the app; the Bearer token identifies the user. Without the Bearer token the server returns 500 ("Object reference not set").
